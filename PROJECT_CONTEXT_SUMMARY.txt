一、项目整体规划
============================================================

项目目标：
做一个原生 iOS SwiftUI App，把 Apple Health 每日步数转化为“小动物旅行机票”。用户把今天的脚步送给小动物，小动物去远方旅行，之后寄回明信片。整体气质必须是温柔、治愈、手帐、水彩旅行小屋，而不是健身打卡工具、效率工具或硬核数据面板。

当前 MVP 范围：
1. 启动流：
   - 首次进入显示欢迎页。
   - 欢迎页完成后显示 Health 连接引导页。
   - Health 可连接，也可“稍后再说”进入主界面。
2. 一级页只保留两个 Tab：
   - 小屋
   - 邮箱
3. 小屋页负责：
   - 显示 Health 状态。
   - 显示小动物和小屋场景。
   - 读取今日步数。
   - 判断是否可赠送机票。
   - 显示赠送确认弹层。
   - 赠送成功后创建旅行。
   - 旅途中显示状态卡。
   - 进入页面时扫描是否有可投递明信片。
4. 邮箱页负责：
   - 展示信封列表。
   - 展示未读/已读/旧明信片。
   - 邮箱为空时显示温柔空状态。
   - 打开全屏明信片详情。
   - 进入页面时扫描是否有可投递明信片。
5. 明信片详情页负责：
   - 用 postcard_template_classic 作为底图。
   - 用 Postcard 模型上的 destination/stamp/animal/template/envelope 资源字段渲染。
   - 所有文字由 SwiftUI 渲染，不烘焙进图片。
6. 设置页作为小屋页入口打开：
   - Apple 健康状态和重新请求权限入口。
   - 通知设置二级页。
   - 明信片收藏二级页。
   - 关于步旅小屋二级页。
7. 内容系统由 ContentManifest.json 驱动：
   - animals
   - destinations
   - postcards
   - rules
8. 用户状态由 SwiftData 持久化：
   - tickets
   - trips
   - postcards/read state
   - travel wish 状态
   - onboarding 状态
   - Health 引导状态

核心技术路径：
- SwiftUI + lightweight MVVM + AppEnvironment。
- AppRepository 是唯一业务 mutation 入口。
- AppUserStateStore 是 repository 后面的用户状态存储协议。
- SwiftDataUserStateStore 是 live 持久化实现。
- InMemoryUserStateStore 是 Preview/Test 实现。
- HealthKitStepCountProvider 通过 StepCountProvider 协议接入。
- FakeStepCountProvider 用于 Preview/Test。
- TicketRuleEngine 处理步数到机票规则。
- PostcardScheduler 处理明信片生成和时间规则。
- ContentManifestLoader 读取 bundled JSON，失败时 fallback 到 SeedData.preview。
- AppCopy 收口 MVP 高频中文文案，当前不引入本地化。
- manifest-owned catalog 不持久化；SwiftData 只保存用户状态和 manifest id。

当前关键业务规则：
- 今日步数 >= 3000，可赠送 1 张机票。
- 每天最多赠送 1 次。
- 有 activeTrip 时不能再次赠送。
- giftTicket 成功后：

  - 将 active wish 改为 traveling。
  - 创建 traveling Trip。
- 第一版旅行规则：
  - 赠送后立即进入 traveling。
  - departedAt + 1 天后可投递 1 张未读明信片。
  - 投递后 trip completed，wish completed。
  - 同一 trip 不重复投递。
- 运行时明信片文案：
  - 从 ManifestDestination 的 postcardTitleTemplate、postcardSubtitle、postcardBodyTemplate 生成。
  - 支持 {animal} 和 {destination} 占位替换。

  - 只做视觉来访，不可点击、不解锁、不寄明信片、不持久化发现状态。

- AppRootView 启动规则：
  - onboardingCompleted == false：显示 OnboardingView。
  - onboardingCompleted == true 且 healthGuideDismissed == false：显示 HealthConnectView。

- 持久化：
  - tickets

  - travel wish state

  - healthGuideDismissed
- 不持久化：
  - 完整 Animal catalog
  - 完整 Destination catalog
  - 静态 manifest 内容
