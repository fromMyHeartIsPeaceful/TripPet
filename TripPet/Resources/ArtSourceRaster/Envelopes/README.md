# Envelopes

Mailbox tray and envelope-state art for the mailbox list.

## Format

- Final app format: PNG `@3x`
- Background: transparent when the asset is layered; opaque only for full paper
  surfaces that are meant to carry SwiftUI text.
- Suggested source size: 1280 x 520 for envelope list backgrounds.
- Leave clear central space for SwiftUI-rendered title, subtitle, date, and status.
