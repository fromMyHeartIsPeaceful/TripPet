# Stamps

Postmark, stamp, and small travel mark assets.

## Format

- Final app format: PNG `@3x` for watercolor marks, or vector PDF/SVG only when
  the mark remains a hand-drawn icon.
- Background: transparent
- Postcard stamp overlays use a transparent `180 x 180` PNG slot.
- Keep opacity soft enough to layer over envelopes and postcards without hurting
  SwiftUI text readability.

## Postcard Stamp Slots

- Current slot assets: `postcard_stamp_airport`, `postcard_stamp_paris`,
  `postcard_stamp_reykjavik`, and `postcard_stamp_lisbon`.
