# Animals

Layerable animal illustrations for the home scene, visitors, route markers, and
postcard selfie overlays.

## Format

- Final app format: PNG `@3x`
- Background: transparent
- Source target size: 1024 x 1024 for main poses and selfies
- Postcard animal overlays use a transparent `240 x 260` PNG slot.
- Keep the same character design across repeated cat assets: round face, tiny
  highlighted bean eyes, pale peach nose, light tabby marks, short paws, thin
  curved tail, and pale sage scarf.

## Current Assets

- `animal_cat_home.png`: resident cat for the cabin home scene.
- `animal_cat_selfie.png`: close half-body cat selfie for postcard layering.
- `animal_visitor_unknown.png`: friendly unknown visitor peeking from a doorway.
- `postcard_animal_cat`, `postcard_animal_dog`, `postcard_animal_rabbit`, and
  `postcard_animal_unknown`: fixed-slot postcard overlays in the asset catalog.
