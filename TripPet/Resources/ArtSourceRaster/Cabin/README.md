# Cabin

Watercolor cottage scene layers and cabin props.

## Format

- Full room backgrounds: opaque PNG `@3x`
- Props: transparent PNG `@3x`
- Suggested source sizes: 1440 x 1440 for `cabin_room_base`; wide transparent
  PNG for table and map props.

## Current Assets

- `cabin_room_base.png`: morning cottage interior without animals or business text.
- `prop_map_table.png`: low wooden table with a hand-drawn map, pencil, and notes.
